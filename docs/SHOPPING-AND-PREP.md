## Every week — master ops checklist

### Friday after cutoff

- [ ] Export / list paid orders only  
- [ ] Print packing slips  
- [ ] Shop to **order count + 1** test/sample (optional)  
- [ ] Print labels with bake number + allergens  

### Bake days

- [ ] Clean surfaces · no pets in kitchen  
- [ ] Handwash · hair tied · clean apron  
- [ ] Oven preheat confirmed (load-shedding plan)  
- [ ] Cool on racks — **never pack hot**  
- [ ] Fridge ≤4 °C for dairy/custard items  

### Collection day

- [ ] Boxes alphabetical / by slot  
- [ ] Tick sheet for handoff  
- [ ] No-shows: photo + message; policy applied  
- [ ] Next week teaser photo  
- [ ] Deep clean same day  
- [ ] Log sales (Business Ledger or spreadsheet)
